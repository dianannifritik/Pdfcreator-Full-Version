## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Virtual Printer Installation** — Easily convert documents to PDF format through a virtual printer setup.
- **Multiple Format Support** — Convert files into various formats including PDF, PNG, JPEG, BMP, and more.
- **Document Combination** — Merge multiple documents into a single PDF for easier management.
- **File Metadata Customization** — Include essential metadata like author and creation date directly in your PDF files.
- **Context Menu Integration** — Print to PDF directly from the file context menu without needing to open another application.

### Advanced Features:
- **Cloud Integration** — Seamlessly upload files to Dropbox or send them via email upon saving.
- **Image Compression** — Reduce file sizes by compressing and resizing images within your PDFs.
- **AES Encryption** — Protect sensitive information with robust encryption options.
- **HotFolder Functionality** — Now available in Hungarian for enhanced accessibility.
